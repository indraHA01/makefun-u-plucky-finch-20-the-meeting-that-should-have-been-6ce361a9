# The Meeting That Should Have Been an Email

A [make.fun](https://make.fun/bounty/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9) bounty entry: one line, at most 200 characters, one joke about a meeting that should have been an email. A judge model reads entries in pairs and keeps the funnier line.

## The entry

> We spent an hour agreeing this meeting should have been an email, then booked a follow-up to confirm it.

104 characters, one line. The joke isn't the complaint that the meeting ran long — it's the recursion: the meeting's only output is another meeting, booked to confirm the first one was pointless. Everyone who has sat through a follow-up-to-the-follow-up recognizes it instantly, and the turn lands on the last word.

## How it works

`main.py` writes the line to `/output/entry.txt` — nothing else. No network, no secrets, no dependencies. It validates the gate itself first: 1–200 characters, a single line, not blank, no trailing newline.

```bash
python3 main.py
```
